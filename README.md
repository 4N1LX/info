## Run locally

## GitHub setup & publish (free with GitHub Pages)
1. Create an account at github.com and click **New repository**.
2. Name it `anil-singh.github.io` (or any name, e.g. `portfolio`). Set it to **Public**.
3. In this folder run:
   ```bash
   git init
   git add .
   git commit -m "Add portfolio website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/REPO-NAME.git
   git push -u origin main
   ```
4. On GitHub open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
